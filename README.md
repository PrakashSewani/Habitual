# Habitual

Build consistency. One day at a time.

## 📱 About

Habitual is a modern habit tracking platform designed to help you build routines, stay consistent, and visualize progress across devices.

Track daily habits, maintain streaks, and turn small actions into long-term behavior.

---

## ✨ Features

* Create and manage habits
* Flexible schedules (daily, weekdays, custom)
* Track completion history
* Streak tracking
* Clean, minimal UI
* Cross-platform (mobile + web)

---

## 🏗️ Tech Stack

### Backend

* .NET (Clean Architecture)
* REST API

### Mobile

* React Native (Expo)

### Web

* Next.js

---

## 📂 Project Structure

```plaintext
src/
 ├── api/        # .NET backend
 ├── mobile/     # React Native app (Expo)
 └── web/        # Next.js app
```

---

## 🚀 Getting Started

### Backend

```bash
cd src/api
dotnet restore
dotnet run
```

### Mobile

```bash
cd src/mobile
npm install
npm start
```

### Web

```bash
cd src/web
npm install
npm run dev
```
