# Habitual

Build consistency. One day at a time.

---

## Users

Primary: Discipline-seeking individuals who want to build and maintain daily routines.
They value clarity, minimal friction, and visual feedback that reinforces positive behavior.

Secondary: Self-improvement enthusiasts who enjoy tracking progress and analyzing patterns over time.

## Product Purpose

Habitual is a personal habit tracking platform. Design SERVES the product; this is a **product** register tool UI.

## Tone

Calm, encouraging, personal. Never corporate, never anxiety-inducing.
The product should feel like a trusted journal, not a performance dashboard.

## Anti-references

- Generic SaaS dashboards with hero metrics
- Productivity tools that induce guilt or urgency
- B2B-style data density and admin-panel aesthetics
- Identical card grids (icon + heading + body)
- Glassmorphism used decoratively
- Gradient text for emphasis

## Strategic Principles

1. **Consistency over intensity**: The UI should reward showing up, not perfection.
2. **Progress over perfection**: Partial completion and streak preservation are celebrated.
3. **Frictionless tracking**: Marking a habit complete must be the fastest interaction on the page.
4. **Calm over hype**: No flashing notifications, no aggressive CTA colors, no anxiety-driven dark patterns.
5. **Personal space**: This is a user's private tool. It should feel intimate, not like a shared workspace.
